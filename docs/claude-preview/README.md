# Claude 手机界面预览

体验：<https://livo.workstudioai.top/claude>。使用原有账号登录，点击底部「我的」。当前默认版仍是根路径 `/`，可在同一设备上打开两个地址对比。

此版本由已配置的 Claude Code MCP 提供视觉 CSS 和第二轮胶囊材质设计，Codex 负责接入、样式范围控制及验证。未将账号数据库或配置凭证提供给设计模型。

## 设计变化

- 三项统计合并为一个连续面板，细分隔线组织数字。
- 重新调整头像、标题、日历与最近打卡的比例和间距。
- 手机底部胶囊改为 60px 高的玻璃质感控件，内部按钮点击区域 48px，450ms 滑动缓停。
- 保留珊瑚色心形、主题配色、17px 起的文字，以及原来的苹果字体优先和自托管字体回退。

`web/claude-preview.css` 来自 Claude 的设计输出。接入时将全部变化限定在手机尺寸，并补充主题选择器冲突修正，保证选中标签白字可读。`/claude` 由服务端复用现有 HTML，仅额外加载这一份样式，并设置不索引；账号、打卡及背景功能与默认版相同。没有新增假数据。

## 验证

- 14 项隔离后端检查通过，包含预览页独立性：默认首页不加载预览样式，两个页面其余 HTML 一致。
- 320、360、390px 手机界面无横向溢出，文字不低于 17px；360×740 六行日历底部约 611px，在导航上方。
- 背景折叠、主题保存、日期操作及退出状态复位通过。
- 六种主题下的双向滑动、快速连续点击、选中文字颜色和固定心形颜色通过；减少动态效果设置正常。1440px 桌面启用或禁用预览样式时，导航和个人页的关键布局与样式一致。
- 截图来自隔离演示账号，不展示正式账号数据。

浏览器验证为 Linux Chromium，真实手机上的系统字体与玻璃效果可能略有差异。
