# Livo 推广素材

## 首发内容

标题：做了一个每天只用点一下的网站

正文：

最近做了 Livo。没有每天必须完成的目标，也没有排行榜。

打开，点一下爱心，今天就留下了一份记录。想说点什么，可以写一句；不想说，也可以什么都不写。

可以在日历里回看记录，换一张喜欢的背景，也能把今天保存成一张分享图。默认不带账号和留言，分享什么由自己选择。

我把界面尽量做得简单，手机和电脑浏览器都能用。欢迎试试，也想听听你觉得还可以怎么改。

体验地址：https://livo.workstudioai.top/about

推荐配图顺序：介绍页 → 今日页面 → 日历记录 → 今日分享图。后台截图不用于公开推广。所有截图来自隔离演示账号，不代表真实运营规模。

## 另外两个标题

- 不催你进步，只记录今天：Livo
- 给今天留一个位置，做了个极简打卡网站

## 15 秒录屏脚本

0–3 秒：介绍页「今天，也在。」；字幕「给今天留一个位置」。

3–7 秒：进入今日页，点一次爱心，展示心跳效果。

7–11 秒：进入「我的」，展示日历和背景切换。不要显示真实账号。

11–15 秒：生成分享图，展示预览；字幕「Livo · 手机浏览器就能用」。

## 素材与后续重点

`screenshots/` 是浏览器实际截图；`今日分享图.png` 是真实分享功能生成的 1080×1440 图片。介绍页本身可以作为推广落地页。当前没有自动发帖、自动拉新或营销消息推送。

下一轮适合按实际使用情况决定：自助删除账号和导出记录、邮箱验证与找回密码、用户自选的轻量提醒。先观察真实留存与反馈，再增加功能；不宣称打卡具有健康监护效果，不编造用户数量。
